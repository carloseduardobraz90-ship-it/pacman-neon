# Pac-Man Neon 🕹️

Um remake moderno e desafiador do clássico Pac-Man, desenvolvido com HTML5, CSS3 e JavaScript.

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como um desafio de programação, trazendo:
- **Visual Neon:** Estilo cyberpunk com brilhos e animações.
- **IA Inteligente:** Fantasmas que calculam rotas e ficam mais rápidos conforme você os elimina!
- **Sistema de Bônus:** Coleta de cerejas para pontuação extra.
- **Dificuldade Dinâmica:** O jogo fica mais intenso à medida que o nível de "fúria" dos fantasmas aumenta.

## 🎮 Como Jogar
- **Controles:** Use as setas do teclado ou as teclas **W, A, S, D**.
- **Objetivo:** Coma todas as bolinhas, capture as cerejas e desvie dos fantasmas!

## 🛠️ Tecnologias
- HTML5
- CSS3 (com animações e efeitos de luz)
- JavaScript (Lógica de jogo e IA)
